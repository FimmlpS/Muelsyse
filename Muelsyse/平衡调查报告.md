## 1. 自设定平衡基准

### 1.1 通用预算（以「能量当量 E」计）

| 资源 | 基准值 | 说明 |
|---|---|---|
| 1 能量 | = 6 单体伤害 | 与原版打击对齐，仅作为最底层单位 |
| 1 能量 | = 5 格挡 | 同上 |
| 1 能量 | = 1 抽牌 | 抽牌按 1:1 折算 |
| 1 能量 | = 4 群体伤害 | 单体 × 0.66 |
| 1 生命 | ≈ 0.8 价值 | 治疗低于格挡（格挡可溢出、生命不可） |
| 1 能量 | = **2 润化** | 「产出侧」给资源卡的默认兑换价 |

> 这张表只用来算「一张牌按费用应该给多少」。**它不代表原版卡牌平衡，也不代表本 MOD 的目标强度。**

### 1.2 润化的两套汇率（本 MOD 的核心问题）

润化在本 MOD 里同时是三种东西，所以有两套不同的「价格」：

**A. 产出汇率**（你获得润化的速度）

| 来源 | 产出 | 每能量 |
|---|---|---|
| 生命吊坠：每打出 1 张牌 +1 | 1 / 牌 | ≈ 1（按 1 牌 ≈ 1 能量） |
| 生命吊坠：回合末每点剩余能量 +2 | 2 / 能量 | **2** |
| 溯途同归（X 费） | 4（升级 5）/ 能量 | 4–5 |
| 海（3 费，升级 2 费） | 20 | **6.7–10** |
| 在雪落处相见（1 费） | ≤ 8–10 张水 | **8–10** |
| 矩阵浪潮（0 费） | 1 + 流形数 | **∞** |
| 新枝（2 费） | 3 | 1.5 |
| 生命之源（1 费 Power） | 每回合 1–2 | 持续 |
| 渐进性润化（1 费 / 升级 0 费） | 1 + 累计成长 | 跨战斗成长 |

**B. 兑现汇率**（你把润化换成什么）

| 出口 | 汇率 |
|---|---|
| 水连击（1 费） | 6 单体伤害 / 润化（升级 9） |
| 水障壁（1 费） | 5 格挡 / 润化（升级 8） |
| 几何（0 费） | 7 伤害 / 润化（升级 10），且丢弃时触发溅射 |
| 16 润化 | 1 个额外流形（3 回合）＝ **协同乘数 +1，持续 3 回合** |
| 20 润化 | 溯源：基础流形 **+20 最大生命、治疗 20、源乘数 +5**（阈值 5×等级） |
| 每张水牌本身 | 每次进弃牌/抽牌/消耗堆：**3（升级 4）随机溅射 + 1 次随机栽培**，且是无限栽培原料 |

**结论：**产出侧按「1 润化 ≈ 1 能量」的遗物基准计，兑现侧却是「1 润化 ≈ 6 伤害 ≈ 1 能量」。也就是说：

- 回合末 1 点剩余能量 → 2 润化 → 兑现 **12 伤害**（水连击）= 基准的 **2 倍**；
- 海 3 能量 → 20 润化 → 兑现 **120 伤害**（水连击/几何）= 基准的 **6.7 倍**；
- 矩阵浪潮 0 能量 → 1+N 润化 → **不限倍率**。

**任何一张「产水卡」都至少是 3 倍收益，这不是单卡问题，而是两套汇率之间的套利空间。**

### 1.3 协同（Together）预算公式

协同的结算规则（`Scripts/Mechanics/TogetherListener.cs`）：

```
玩家实际伤害  = floor(面板伤害 ÷ 2)          （最低 1）
每个流形伤害  = 同一「显示伤害」（已含协同减半）
总伤害        = 显示伤害 × (1 + 存活流形数 N)
```

- **伤害**：面板 × (1+N) ÷ 2，随 N 线性放大。
- **格挡**：**不减半**（`AfterBlockGained` 直接取全值），每个流形获得 `min(格挡, 阈值)`。
- **能力**：层数取 `ceil(面板 ÷ 2)`，然后每个流形再施加一次同样的层数。

因此协同牌的「合理面板」应当是普通牌预算的 **1 / (1 + E[N])**：

| 期望流形数 N | 总倍率 | 协同牌面板预算（1 费） |
|---|---|---|
| 1（第 1 回合） | ×2 | ≈ 3 伤害 |
| 2–3（战斗中盘） | ×3–4 | ≈ 2–3 伤害 |
| 4–5（水量充实后） | ×5–6 | ≈ 1–2 伤害 |
| 6–8（如水随形 / 紧急衍生） | ×7–9 | ≈ 1 伤害 |

> 一个 6 面板的协同攻击（显示 3）在 N=4 时总输出 15，已经等于 2.5 费；所以协同卡的**数值本身**不是问题，**流形数量**才是。

### 1.4 稀有度与费用预算

| 稀有度 | 预算（E） | 备注 |
|---|---|---|
| Common | 1.0 | 无条件的标准强度 |
| Uncommon | 1.15–1.25 | 可带 1 个小条件 |
| Rare | 1.4–1.6 | 可带 1 个中等条件或明显上限 |
| 0 费 | 0.6 | 且不应同时产出资源 |
| 固有 / 保留 / 消耗 | ±10% | 只做小幅修正 |

### 1.5 本报告的「明显超模」判定线

满足任意一条即列入超模：

1. 单卡实际收益 ≥ 同费预算的 **2 倍**；
2. 单卡把某资源速率抬到基准的 **3 倍以上**（如 2 润化/能量 → 6+）；
3. 存在 **无上限或自我放大**的结构（随回合/流形数/牌堆单调增长）；
4. 让另一条成本线 **失效**（失肥、能量、手牌上限、流形上限、牌堆上限）。

## 2. 体系经济核算

### 2.1 润化收入（每回合大致量级）

以「中盘、5 张出牌、3 能量」为例：

| 来源 | 量 |
|---|---|
| 每打出 1 张牌 +1 | 5 |
| 回合末剩余能量 ×2（0 费卡组满额） | 6 |
| 单张产水卡（海 / 相见 / 矩阵浪潮） | 10–20 |
| **合计** | **≈ 11–31 润化 / 回合** |

对照 16 / 20 的两个阈值：**平均每 1–2 回合就能触发一次流形/溯源**。也就是说，遗物设计的两个「大招」实际上变成了常规节奏——这是本 MOD 最根本的强度膨胀来源。

### 2.2 润化支出去向

| 缺口 | 代价 | 折合 |
|---|---|---|
| 1 个额外流形（3 回合） | 16 润化 | ≈ 2–4 张协同牌的额外伤害 |
| 1 次溯源 | 20 润化 | +20 最大生命 + 治疗 20 + 阈值 ×5 |
| 1 次群体/单体兑现 | 水连击 1 费 / 水障壁 1 费 / 几何 0 费 | 6 / 5 / 7 伤害或格挡 · 每润化 |

**注意：溯源是「乘法」不是「加法」。** 阈值 = 流形等级 × 源层数，而源层数只加在**基础流形**上；基础流形又是额外流形的模板（额外流形复制基础流形的最大生命与等级）。所以一次溯源同时提升：

- 基础流形的**减伤吸收量**（阈值）；
- **愿望凝结**的伤害（复制最大生命）；
- **协同格挡**的上限（min(格挡, 阈值)）；
- 额外流形的**血量模板**。

**一条润化，喂四个系统。** 这是 T0 级设计的根源。

### 2.3 能量与抽牌收支

| 类型 | 卡 | 净收益 |
|---|---|---|
| 0 费净赚能量 | 精调（+1/2）、落叶（作原料 +2/3） | +1 ~ +3 能量 |
| 0 费抽牌 | 苍翠（抽到时 1/2）、夜愿（进入抽牌堆 2）、复合型养料（养料 +2/3 抽） | 持续 |
| 抽牌爆发 | 浅层非熵适应（每张手牌 +1 抽）、种一颗星星（抽至 10）、终末的岁月（第二手牌）、水循环（最多 20 抽） | 5–10 抽 |
| 能量循环 | 璀璨（进抽牌堆 +1）、深层反映（最贵手牌打出 +1） | 每洗牌一次 |

**抽牌与能量在本 MOD 中都是「可再生的」**：只要牌堆循环，苍翠/璀璨/夜愿每轮都给一次收益；而「水牌」每轮还会额外提供 3 点溅射。这让「防御性拖延」本身变成一种不亏的玩法。

### 2.4 三个正反馈环

```
环 A：能量 → 润化 → 最大生命/阈值 → 更耐打 → 更多回合 → 更多能量
环 B：流形数 N → 矩阵浪潮产水 → 润化 → 更多流形 → N 更大
环 C：栽培 → 永久数值 → 更好清场 → 更多 0 费回合 → 更多栽培
```

三条环都**没有硬性上限**（除了流形 4 个的软上限，而 `ignoreCap` 又能绕过）。T0 项基本都在这三条环上。

## 4. 分级超模推荐报告

> 调整方向给的是**区间与选项**，不是最终数值；同一项建议只选 1 条主改，避免叠加过修。

### T0 — 机制级（先动这些，因为它们放大所有其他卡）

#### T0-1 愿望凝结（`Scripts/Cards/Attack/CondensateWish.cs`）

- **现状**：2 费（升级 1 费），伤害 = 所有存活流形的当前生命总和；非协同，不再乘 N。
- **超模依据**：基础流形 5 最大生命，每次溯源 +20；额外流形复制基础流形的最大生命。
  - 3 次溯源后：基础 65 生命，1 个额外流形 → **130 伤害 / 2 费**；
  - 4 个额外流形 → **325 伤害 / 2 费**（升级后 1 费）。
  - 基准 6 伤害/能量 → **10–50 倍**。
- **为什么是 T0**：它不是孤立强卡，而是把「溯源堆血量」的防御收益**再卖一次**变成伤害。防御与攻击共用同一个资源，等于没有取舍。
- **调整方向（选一）**：
  1. 伤害改为「基础流形当前生命的 50%」（去掉额外流形复制）；
  2. 伤害改为「所有流形**已损失**生命之和」；
  3. 打出后**消耗**所有流形的等量生命；
  4. 保留公式但加伤害上限（如 30）。
- **不改的风险**：任何「海 / 溯源」路线都会自动获得一张终结技，Boss 战被一张牌结束。

#### T0-2 水连击 / 水障壁 / 几何（`Scripts/Cards/Attack/WaterWave.cs`、`Skill/WaterShield.cs`、`Attack/Geometry.cs`）

- **现状**：把「所有牌堆中的水」按 6 / 5 / 7（升级 9 / 8 / 10）逐张兑现；水被消耗/丢弃时每张再触发 3–4 点随机溅射。
- **超模依据**：
  - W=8 时：水连击 48 伤害 + 24 溅射，1 费；水障壁 40 格挡 + 24 溅射，1 费；几何 56 伤害 + 24 溅射，**0 费**。
  - 基准 6 / 5 / 3.6 → **8–20 倍**。
- **为什么是 T0**：**水牌的产出远多于消耗**（不竭之泉、矩阵浪潮、新枝、生命之源、相见、水循环），只有水连击/水障壁/几何/生灵的回响会真正移除它们。W 在多数战斗里逐回合上升，这三张牌的强度也随之增长——**没有上限**。
- **调整方向（选一）**：
  1. 兑现率降到 3–4 / 水（升级 4–5）；
  2. 只统计**手牌**（或手牌 + 弃牌），不再统计抽牌堆；
  3. 每张水每回合只能被兑现一次（加「本回合」标记）；
  4. 水连击/水障壁改为「消耗最多 X 张水」。
- **不改的风险**：水系卡组的输出曲线是「越打越强且没有刹车上限」，且 0 费的几何让水牌 → 伤害的转换完全不消耗能量。

#### T0-3 矩阵浪潮（`Scripts/Cards/Skill/MatrixWave.cs`）

- **现状**：0 费，自身与每个流形各放 1 张水进手（升级为水+，溅射 4）。
- **超模依据**：
  - N=4 → **5 张水 / 0 费**；按兑现汇率 = 30 伤害或 25 格挡，且是 5 个无限原料 + 5 次溅射。
  - 它是 T0-2 三件套的**0 费入口**，也是流形数 N 与润化之间的**正反馈齿轮**（N 越大产水越多 → 溯源越多 → 流形越多）。
- **调整方向（选一）**：
  1. 费用改为 1；
  2. 改为「所有流形各 1 张」（不含自身），去掉基础 +1；
  3. 每回合限一次；
  4. 固定为 1 张（升级 2 张），去掉 N 缩放。
- **建议优先选 4 或 2**：保留「流形越多越强」的手感，但削掉无上限。

#### T0-4 生命吊坠：回合末能量→润化（`Scripts/Relics/LifeCircle.cs:85-100`）

- **现状**：回合结束时，每点剩余能量提供 **2 点**润化（`Math.Min(energy, maxEnergy) * 2`）。**这是 StS2 移植新增的（S1 无此机制）**。
- **超模依据**：
  - 1 能量 → 2 润化 → 兑现 12 伤害，是基准的 **2 倍**；
  - 0 费卡组可以「整回合不花能量」，回合末满额兑换 → 每回合稳定 +6~10 润化；
  - 与 0 费密度**正反馈**：0 费牌越多 → 能量剩得越多 → 水越多 → 越容易抓到 0 费牌循环。
- **调整方向（选一）**：
  1. 每 2 点剩余能量换 1 润化（减半）；
  2. 每回合上限 4 润化；
  3. 改为「每点剩余能量 +1 润化」；
  4. 改为只结算**未打出的牌数**而不是能量。
- **注意**：这是公开发布在遗物文本里的机制，改动会影响整体节奏而非单卡；若保留，则建议同时压低 T0-2 的兑现率。

#### T0-5 永久栽培写入 × 0 费栽培器 × 永不失肥原料

- **涉及**：
  - `Scripts/Mechanics/Cultivate/CultivateCmd.cs:147-164`（`Apply` 写入 `DeckVersion`，跨战斗永久）；
  - `Scripts/Cards/Skill/BornShoots.cs`（0 费，栽培 1/2）；
  - `Scripts/Cards/Skill/EndlessSpring.cs`、`Skill/EternalGreenfield.cs`（不会失肥）；
  - `Scripts/Cards/Status/Water.cs`（无限原料，并携带自身栽培）。
- **现状**：栽培的**收益永久写入牌组**，而原料的「失肥」只在本场（`CultivateDryModifier` 无存档数据）。0 费栽培器让「本回合的节奏成本」也接近 0。
- **超模依据**：
  - 生枝（0 费）+ 5 张无限原料 → 目标牌**永久 +6/+6**，外加落叶 +2 能量、花语 +3 水、水牌携带的栽培；
  - 每场战斗可重复，跨战斗累积；
  - `Cap = 栽培量 + 无限原料数量`，而「水」和「散孢」都能大量堆叠 → 单次栽培可以塞进 10+ 个材料。
- **调整方向（选一，先确认设计意图）**：
  1. 承认永久栽培是设计目标 → 只砍「0 费栽培器 + 0 成本原料」：生枝改为 1 费；不竭之泉/绿地加「每回合只能作为原料一次」；
  2. 战斗内栽培改为 **combat-only**（只写 `CombatState` 副本），牌组栽培仅在篝火/奖励节点写入；
  3. 同一张牌每场战斗的栽培次数上限（如 3 次）；
  4. 原料「失肥」持续到下一场战斗，形成真实成本。
- **风险**：这是从 S1 继承的设计（`CultivateSaveData` 在 S1 就存在），改它会改变整个 MOD 的成长感。**若确认是设计目标，请只改「0 费 / 无成本」的部分，不要动永久性本身。**

### T3 — 边缘 / 组合技 / 观察项

1. **渐进性润化**（`Skill/GraduallyWater.cs`）：1 费（升级 0），润化 = 1 + 累计成长，成长跨战斗永久 +1。长局线性成长，但每场只打 1 次（消耗），影响有限。
2. **花语**（`Skill/WordOfFlower.cs`）：基础牌、保留、不可打出、无限原料 +3/5 润化；每次使用即消耗 → 每场 1 次。作为基础牌给 3 润化偏高，但可控。
3. **深层反映**（`Skill/DeepReflect.cs`）：1/0 费，把 +1 能量挂到最贵的手牌上，自身费用 +1/本场。属于「费用转移」，在重牌卡组里价值高、0 费卡组里几乎无用 —— 观察即可。
4. **苍翠/夜愿/璀璨升级后移除「不可打出」但费用仍为 -1**：可能变成「可打出的 -1 费牌」，需确认引擎如何处理负费用；若可打出，则是免费循环抽牌/能量（潜在循环）。
5. **紫颂可自动打出 Power/Token**：随机复制的抽牌堆牌包含 Power 与 Token，自动打出 Power 可能产生未预期的持续效果。
6. **种一颗星星升级无效果**（`OnUpgrade` 空）：升级奖励缺失，建议补（如栽培 +2 或抽至 11）。
7. **生命吊坠文本未提及 20 润化的溯源效果**（`localization/zhs/relics.json` 只写了 16 → 额外流形）：玩家看不到「+20 最大生命 / 源 ×5」，导致这部分强度是「隐藏的」，也让平衡讨论缺少玩家侧感知。
8. **海是 Power 类型但效果是一次性**：类型/文本/图标不一致，建议改为 Skill 或改成持续 Power。

## 5. 建议的调整顺序（最小改动测试包）

如果只想先做 4 处改动验证方向，推荐顺序：

1. **矩阵浪潮**：0 费 → 1 费（或去掉 N 缩放）。它是所有水链的入口，改它能立刻看到水系整体强度下降，且不破坏卡组多样性。
2. **水连击 / 水障壁 / 几何的兑现率**：6/5/7 → 4/4/5（升级 5/6/7）。直接压缩「润化 → 伤害」的汇率。
3. **生命吊坠回合末转换**：2 润化/能量 → 1 润化/能量（或每回合上限 4）。压低基础收入。
4. **愿望凝结**：改为「基础流形当前生命的 50%」。切断「堆血 → 秒杀」的二次变现。

> 这 4 处都不动「协同 / 栽培」的结构，改动量小、回滚容易，能验证「汇率修正」是否是主要矛盾。若改完仍偏强，再处理 T0-5（永久栽培）与 T1 的流形入口。

**如果只能改一处**：改「矩阵浪潮」。它是唯一同时连接「流形数 N」「润化产出」「水牌数量」三个系统的 0 费节点，杠杆最大。

## 6. 附录

### 6.1 关键计算示例

**示例 A：海 + 水连击**
- 3 费打出海 → +20 润化；下回合 1 费水连击（假设牌堆有 6 张水）→ 6×6 = 36 伤害 + 18 溅射。
- 合计 4 费 → 36 单体 + 18 群体 ≈ 9 单体伤害/能量 + 4.5 群体/能量，约为基准的 1.5–2 倍（这部分合理）；但 20 润化同时触发 **1 次溯源**（+20 最大生命、+20 治疗、源 ×5）——这才是超模部分。
- 若把「水连击」换成「几何」（0 费），4 费 → 42 单体 + 18 群体，约 10.5/能量。

**示例 B：愿望凝结**
- 战斗第 5 回合，3 次溯源（60 润化）：基础流形最大生命 5 + 60 = 65；额外流形 1 个 → 总生命 130。
- 愿望凝结（2 费）→ 130 伤害；升级后 1 费 → **130 伤害/能量**，基准 6。

**示例 C：散孢**
- 战斗第 4 回合，散孢已复制 5 次，手牌 5 张散孢：0 费打出 5 张 = 30 伤害 + 5 次「打出牌 +1 润化」= 5 润化 + 5 个无限原料。
- 若这 5 张作为原料参与一次栽培：栽培上限 = 栽培量 + 5，单体永久 +5/+5 以上。
